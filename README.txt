MY PERSONAL WEBSITE — START HERE

1. Replace every occurrence of Name, YOUR CITY, YOUR INTERESTS, YOUR HOBBIES,
   YOUR-EMAIL@example.com and YOUR-DOMAIN.example with your own details.
2. Add your profile image as images/profile.jpg. The current About page uses a
   styled placeholder; update about.html to use:
   <img class="profile-photo" src="images/profile.jpg" alt="Portrait of Name">
   Add CSS for .profile-photo if desired.
3. Open index.html in a browser to preview the site locally.
4. To edit in Xcode: open the project folder in Xcode (File > Open).
   You can also use a browser to preview the HTML files.
5. Before publishing, change canonical URLs, sitemap.xml and robots.txt to your
   real HTTPS domain. Do not leave example-domain URLs in production.
6. For a free initial address, deploy the complete folder to GitHub Pages (your-site.github.io) or Netlify (your-site.netlify.app). Choose your actual site address first, then replace the example canonical URLs in every HTML file, sitemap.xml and robots.txt with that real HTTPS address.
7. Add the verified domain to Google Search Console and submit /sitemap.xml.
   Indexing and ranking are not guaranteed; Google decides what to index and rank.

ADDING ARTICLES:
- The sample cards are data in script.js.
- For a real article, create a separate HTML file (for example, my-first-post.html)
  with a unique title, meta description, canonical URL and article text.
- Add an entry to the articles array in script.js with url:"my-first-post.html".
- Add the article URL to sitemap.xml after publishing.
